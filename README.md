# Java 2D Platformer – Rogue Alley

A fast, **pixel-art 2D fighter** with arcade vibes. Think “Mario-style movement,” but instead of stage-clearing, it’s an **endless roguelike loop**: survive as long as you can, rack up KOs, and chase your high score.

[![Watch the demo](https://img.youtube.com/vi/Pre0s72SRNE/0.jpg)](https://youtu.be/Pre0s72SRNE)

---

## Type & Genre
- **Type:** Game  
- **Genre:** Pixel • 2D Fighter • Casual • Roguelike

---

## Concept
In a **dark, narrow street**, your character is **ambushed by a criminal gang**. Use tight movement and simple strikes to outlast waves of enemies. There’s **no timer**—you play until you die. The game **records your high score** so you can keep improving.

---

## Core Mechanics
- **Endless loop:** enemies keep coming; each knockdown grants **+1 score**.
- **Lives/health:** survive as long as possible; run ends on death.
- **High Score:** best run is saved and shown on the title/game over screen.
- **Combat:** quick **punch** and **kick** with distinct timing/range; basic hit-stun.
- **Movement:** responsive platforming (run, jump) with grounded/air control.
- **Feel:** short startup/active/recovery frames for attacks (arcade mood).
